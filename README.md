# CAREWAVE DASHBOARD

2.90 × 4.30m 실증 공간의 방 배치를 바탕으로 만든 병실 A-01에서 7종 기본 이벤트와 4종 낙상을 재생하는 한국어 발표용 대시보드입니다. React, Vite, TypeScript, Three.js와 SVG를 사용하며 모든 측정값은 앱에 포함된 가상 데이터에서 생성됩니다.

## 실행

Node.js 22.13 이상과 pnpm 11을 사용합니다. 이 디렉터리에서 다음 명령을 실행하고 터미널에 표시된 주소(기본 `http://localhost:5173`)를 엽니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

첫 화면의 **기술 소개**(`#technology`)에서 실증 공간 2D 배치도, 3D 점군과 그래프를 확인하고 11개 시나리오를 재생할 수 있습니다. **로그인**(`#login`)을 누른 뒤 아이디와 비밀번호에 각각 `carewave`를 입력하면 기관용 대시보드(`#demo`)가 열립니다. 체험 로그인은 브라우저 탭의 세션에 저장합니다.

기관용 대시보드는 10개 병실의 위험 등급과 센서 상태를 보여줍니다. 병실을 선택하면 대상자 정보, 생활 요약, 타임라인, 이벤트 이력, 센서 운영 상태를 볼 수 있습니다. **알림 내역**(`#alerts`)에서 확인 여부를 필터링하고 주의·위험 경보를 열 수 있습니다. 확인 상태는 브라우저에 저장됩니다. 기관 화면과 문자 발송 상태는 시연 데이터입니다. 사이드바의 **서비스 소개**를 누르면 소개 화면으로 돌아옵니다.

**대상자 관리**(`#subjects`)에서 호실과 대상자 이름을 선택하면 모니터링 카드와 같은 상세 화면을 엽니다. 모니터링의 **호실 추가**와 **호실 관리**에서 추가·수정·삭제할 수 있으며 변경 사항은 브라우저에 저장됩니다. 병실 상세의 **생활 리포트**에서 대상자별 날짜 기록을 확인할 수 있습니다. 별도 시연 리포트는 `src/reportData.ts`에서 대상자 ID와 날짜를 기준으로 생성합니다.

## 시연

- 이벤트 버튼을 누르면 해당 시나리오가 0초부터 재생됩니다. 일시정지, 다시 재생, 재시작, 0.5×~4× 배속, 타임라인 탐색을 사용할 수 있습니다.
- 낙상 4종은 각각 다른 경로와 높이, 속도 변화를 사용합니다. 낙상은 빨간색, 야간이탈은 주황색 모달로 표시합니다. 장시간 미움직임은 상태 카드와 그래프에 주황색으로 표시합니다.
- 경고의 **확인**을 누르면 모달이 닫힙니다. 위험도와 감지 기록은 같은 재생에서 유지됩니다. 시나리오 선택 또는 재시작으로 초기화됩니다.
- 우측 상단의 **전체 화면**으로 발표 모드를 켜고 끌 수 있습니다. 전체 화면을 제한하는 내장 브라우저에서는 현재 뷰포트에 맞춘 발표 모드로 전환됩니다. 일반 데스크톱과 노트북은 한 화면에 표시하며 좁은 화면은 패널을 세로로 재배치합니다. WebGL2를 사용할 수 없는 브라우저에서는 동일한 좌표의 점군을 SVG 등각 투영으로 표시합니다.

## 테스트 및 정적 배포

```sh
pnpm test
pnpm build
pnpm preview
```

`pnpm test`는 11개 이벤트의 샘플, 감지 시각, 재실 전환과 4종 낙상의 높이 감소 및 경로 차이를 확인합니다. `pnpm build`는 TypeScript 검사와 정적 파일 생성을 실행합니다. `pnpm preview`는 기본 주소 `http://localhost:4173`에서 빌드 결과를 확인하는 용도입니다.

공유하려면 빌드로 생성된 `dist/`의 내용을 정적 호스팅에 배포하고 호스팅 주소를 전달합니다. 빌드형 호스팅에서는 프로젝트 루트를 `carewave-simulator`, 빌드 명령을 `pnpm build`, 출력 디렉터리를 `dist`로 설정합니다. 상대 경로 자산을 사용하므로 하위 경로에도 올릴 수 있습니다. 압축해 전달할 경우 받는 쪽에서 정적 HTTP 서버를 통해 `index.html`을 엽니다. [Vite 정적 배포 안내](https://vite.dev/guide/static-deploy.html)

## 시나리오 데이터 수정

`src/scenarios.ts`의 키프레임은 `[초, x, y, z, 이동속도, 움직임강도, 재실여부]` 순서입니다. 거리 단위는 m이며 속도 단위는 m/s입니다. 키프레임에서 `timestamp`, `x`, `y`, `z`, `speed`, `presence`, `zone`, `intensity`, `event_type`을 가진 30 Hz 샘플을 만듭니다. `detectionTime`이 이벤트 시점을 지정합니다.

방과 가구 치수는 `src/room.ts`에서 관리합니다. 시뮬레이션 좌표는 평면도 왼쪽 위를 원점으로 사용합니다. 스크린샷에 치수가 없는 가구와 문 위치는 화면의 비율을 기준으로 배치했습니다.

하나의 `requestAnimationFrame` 시간축에서 현재 샘플을 보간합니다. 2D 마커와 경로, Three.js 점군, 상태 카드 및 세 그래프가 같은 샘플과 경과 시간을 사용합니다. 이벤트 시각은 재생 시작 시각과 감지 오프셋을 합산해 한국 표준시로 표시합니다.
